# Weather App with API Integration

## Project Description

The Weather App is a single-page web application developed using HTML, CSS, and JavaScript that fetches real-time weather data from the OpenWeather API. Users can search for any city to view the current temperature and weather conditions. The application also changes the background dynamically based on the weather condition, such as sunny, rainy, or cloudy weather.

---

# Objective

The objective of this project is to learn and implement:

* API integration using JavaScript
* Asynchronous programming with `fetch()`
* Handling JSON data
* DOM manipulation
* Dynamic UI updates
* User input handling

---

# Features

* Search weather by city name
* Displays current temperature
* Displays current weather condition
* Dynamic background changes based on weather
* Real-time data fetched from OpenWeather API
* Simple and responsive user interface

# How the Application Works

1. The user enters a city name in the search bar.
2. The application sends a request to the OpenWeather API.
3. The API returns weather information in JSON format.
4. JavaScript extracts the required data.
5. The application displays:

   * city name
   * temperature
   * weather condition
6. The background changes dynamically according to the weather condition.
